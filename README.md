# Ihab AbuMahadi — Portfolio Version 3

A free GitHub Pages website with a redesigned academic researcher / AI engineer homepage, portrait, and digital QR card.

## Publish
1. Back up your current repository (Code → Download ZIP).
2. Upload **all files and the assets folder** to the root of your existing GitHub Pages repository.
3. Commit changes to `main`; Pages should deploy automatically.
4. Hard-refresh the live site (Ctrl+Shift+R).

## Files
- index.html: redesigned homepage
- research.html / projects.html: existing research and projects pages retained
- style.css / script.js: site styles and theme control
- assets/ihab-portrait.jpg: cropped original photo #3
- assets/conference-2026.png: original conference photograph
- assets/portfolio-qr.png: portfolio QR code

## Important
The research and career descriptions are inherited from Version 2. Review publication statuses and dates before treating them as verified. The professional title is user-requested branding. No credentials or private files are included.
