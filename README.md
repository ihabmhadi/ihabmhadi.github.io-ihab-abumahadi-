# Ihab AbuMahadi — Portfolio V6

## Publish on GitHub Pages
Upload **all files and the assets folder** from this directory to the root of your existing repository, replacing old files with the same names. Commit to `main`. Wait for Pages deployment and hard-refresh the site (Ctrl+Shift+R).

## Approved hero design

## Collaboration portal
`collaborate.html` is a dedicated public proposal page with partnership type, project category, project stage, proposal description and consent. It is ready for GitHub Pages.

### Submission methods
**Default:** prepares an email draft to ihab.mhadi@gmail.com. The visitor must press Send in their email client. No online database, private dashboard, or automatic receipt exists in this mode.

**Recommended hosted option:** create a Formspree form, verify its email address and configure `portal-config.js` with the exact endpoint supplied by Formspree. Formspree can receive submissions and show them in its private account dashboard (subject to its plan/settings). Once a successful response is received, the site shows a proposal reference. This reference is generated by the browser and is not a secure sequential ID or proof of acceptance. For authoritative server-issued IDs, statuses, secure logins, and an owned admin portal, build a backend/database.

**Important:** Do not put passwords, tokens or secret API keys in static GitHub Pages files. Add spam protection and a privacy notice before collecting production submissions. Test with your own email before public launch.
